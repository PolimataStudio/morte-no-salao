📖 SOBRE O PROJETO
Morte no Salão de Beleza é uma Landing Page premium desenvolvida para apresentar e promover o romance homônimo, uma história de fé, superação e recomeço. O projeto combina uma identidade visual sofisticada com uma experiência de usuário imersiva, criando um ambiente digital que reflete a atmosfera do livro: acolhedora, misteriosa e transformadora.

"No salão 'Estilo Corte', as cadeiras guardam segredos e as tesouras cortam mais do que cabelos."

🎯 OBJETIVOS
Promoção do Livro: Apresentar a obra de forma atrativa e profissional.

Captura de Leads: Coletar e-mails de interessados para receber o primeiro capítulo.

Engajamento: Conectar leitores com o universo da história.

Direcionamento: Facilitar o acesso ao WhatsApp e Instagram do autor.

Autoridade: Estabelecer uma presença digital de alto nível para o autor.

🔍 PROBLEMA RESOLVIDO
Autores independentes enfrentam desafios na divulgação de suas obras. Este projeto soluciona:

Visibilidade: Criação de uma presença digital profissional.

Credibilidade: Design premium que transmite qualidade e seriedade.

Conversão: Sistema de captura de leads integrado e funcional.

Multiplataforma: Experiência otimizada para todos os dispositivos.

Performance: Carregamento rápido e otimizado para SEO.

Clone o repositório

bash

bash
cd morte-no-salao-de-beleza
Abra o arquivo index.html no navegador

bash
# Com VS Code (Live Server)
code . && npx live-server

# Ou simplesmente abra o arquivo
open index.html

❓ FAQ
📌 O livro é baseado em fatos reais?
Embora seja ficção, a história é inspirada em observações e experiências reais de mulheres que frequentam salões de beleza e encontram ali um espaço de acolhimento.

📌 Qual o público-alvo do livro?
O livro é indicado para leitores que apreciam dramas humanos, histórias de superação e temas como fé, perdão e recomeço. É uma leitura envolvente para jovens e adultos.

📌 Como posso comprar o livro?
Você pode adquirir o livro diretamente pelo WhatsApp ou pelas principais livrarias online. Clique no botão "Comprar pelo WhatsApp" para mais informações.

📌 Vou receber o livro em formato digital ou físico?
Oferecemos ambas as versões. Ao se cadastrar, você receberá o primeiro capítulo em PDF. Para a obra completa, consulte nossas opções de compra.

📌 O site é gratuito?
Sim! O site é totalmente gratuito para navegação e leitura do capítulo inicial. Apenas a obra completa e produtos exclusivos são comercializados.

📌 Como o Static Forms funciona?
O Static Forms é um serviço que permite receber envios de formulários sem necessidade de backend. Seus dados são enviados diretamente para o e-mail configurado.
